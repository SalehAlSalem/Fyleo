# صفحة الإدارة - Fyleo Admin Page

## نظرة عامة
صفحة إدارة متكاملة لإدارة الفئات الأكاديمية، المواد الدراسية، والملفات المرفوعة في منصة Fyleo.

## المتطلبات
- يجب أن يكون المستخدم مسجل دخول
- يجب أن يحمل المستخدم تسمية (label) "admin" في Appwrite Authentication

## كيفية إضافة تسمية Admin للمستخدم

### من لوحة تحكم Appwrite:
1. افتح مشروع Fyleo في Appwrite Console
2. انتقل إلى Auth → Users
3. اختر المستخدم المطلوب
4. في قسم Labels، أضف: `admin`
5. احفظ التغييرات

### باستخدام Appwrite CLI:
```bash
appwrite users updateLabels \
  --userId [USER_ID] \
  --labels admin
```

## الأقسام الرئيسية

### 1. إدارة الفئات والمواد (Categories Management)
- **الوظائف:**
  - إضافة فئة أكاديمية جديدة
  - تعديل بيانات الفئة (الاسم بالعربي والإنجليزي، الوصف، الأيقونة، اللون، الترتيب)
  - حذف فئة
  - تفعيل/تعطيل الفئة

- **الحقول المطلوبة:**
  - الاسم بالعربية (nameAr) *
  - الاسم بالإنجليزية (nameEn) *
  
- **الحقول الاختيارية:**
  - الوصف بالعربية (descriptionAr)
  - الوصف بالإنجليزية (descriptionEn)
  - الأيقونة (icon) - Emoji
  - اللون (color) - Hex Color
  - الترتيب (order) - رقم
  - الحالة (isActive) - نشط/غير نشط

### 2. إدارة المواد الدراسية (Materials Management)
- **الوظائف:**
  - عرض جميع المواد مع pagination
  - تصفية المواد حسب الفئة
  - البحث في المواد بالعنوان
  - نقل مادة من فئة إلى أخرى
  - حذف مادة

- **المعلومات المعروضة:**
  - عنوان المادة
  - الوصف
  - الفئة المرتبطة
  - المقرر (Subject)
  - اسم الملف
  - المستخدم الذي رفع المادة
  - عدد التحميلات

### 3. إدارة الملفات المرفوعة (Files Management)
- **الوظائف:**
  - عرض جميع الملفات من جميع المستخدمين
  - تصفية الملفات حسب الفئة
  - البحث عن ملف بالاسم
  - تصفية حسب المستخدم
  - تعديل اسم الملف
  - نقل ملف إلى فئة أخرى
  - حذف ملف (يحذف المادة المرتبطة أيضاً)

- **الأعمدة المعروضة:**
  - اسم الملف
  - المالك (uploadedBy)
  - المادة المرتبطة
  - الفئة
  - حجم الملف
  - عدد التحميلات
  - إجراءات (تعديل/حذف)

## ملاحظات مهمة
1. جميع العمليات تحدث مباشرة على قاعدة البيانات
2. حذف فئة لا يحذف المواد المرتبطة بها تلقائياً
3. حذف ملف يحذف المادة المرتبطة به
4. يمكن نقل المواد بين الفئات بسهولة
5. الفئات غير النشطة (isActive: false) لا تظهر للمستخدمين العاديين
